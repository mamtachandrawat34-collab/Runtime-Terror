# Desi Arcade Game 

This is a simple **p5.js arcade game collection** built using JavaScript and HTML5 Canvas.

## Features

- Three mini-games in one project
- Jalebi Spinner batter-flow gameplay
- Cricket Gully timing-based hitting
- Dhol Beat rhythm gameplay
- Simple character interactions
- Shape-based visuals with no external assets
- Menu navigation with keyboard controls

## Games Included

- **Jalebi Spinner**
- **Cricket Gully Sixer**
- **Dhol Beat Festival**

## Technologies Used

- JavaScript
- p5.js
- HTML5 Canvas

## How to Run

- Open the project in the p5.js Editor  
- Or run the `index.html` file in a browser
- Press `1`, `2`, or `3` to select a game
- Press `M` to return to the menu

## Controls

- `1` - Play Jalebi Spinner
- `2` - Play Cricket Gully Sixer
- `3` - Play Dhol Beat Festival
- `SPACE` - Main action
- `M` - Back to menu
- `R` - Restart current game
