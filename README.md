# Desi Arcade Game 🎮

This is a simple browser-based arcade game collection built using JavaScript, p5.js, and Howler.js.

The project includes three mini-games: Jalebi Spinner, Cricket Gully Sixer, and Dhol Beat Festival. Each game has its own gameplay style, visuals, score system, and sound effects.

## Features

Three mini-games in one project  
Main menu to select games  
Keyboard and mouse controls  
Jalebi Spinner drawing gameplay  
Cricket Gully timing-based gameplay  
Dhol Beat rhythm gameplay  
Score and combo system  
Sound effects using Howler.js  
Particle effects for steam, bubbles, and glass  
Screen shake and flash effects  
Restart and back-to-menu options  
User-friendly interface  

## Games Included

Jalebi Spinner  
In this game, the player uses the mouse to draw a spiral like a jalebi. The game shows a frying pan, batter trail, steam, and sizzle effects.

Cricket Gully Sixer  
In this game, the player presses SPACE at the right time to hit the ball. A perfect hit gives a sixer, and if the ball hits the window, a glass breaking effect is shown.

Dhol Beat Festival  
In this game, beats fall from the top of the screen. The player presses SPACE when the beat reaches the hit line. Perfect hits increase the combo and play a pop sound.

## How to Run

Download or clone the project  
Open the project folder  
Make sure all sound files are inside the assets folder  
Open the index.html file in a browser  
Click once on the game screen to unlock audio  
Use keys 1, 2, and 3 to select games  

## Controls

1 - Play Jalebi Spinner  
2 - Play Cricket Gully Sixer  
3 - Play Dhol Beat Festival  
SPACE - Main action for Cricket and Dhol  
Mouse Hold - Draw Jalebi  
M - Back to menu  
R - Restart current game
